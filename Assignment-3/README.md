# Assignment 3 – Advanced Task Board

A Task Board application built with **React, TypeScript, and Vite**, featuring advanced state management, inline editing, task prioritization, sorting, and persistent local storage.

# Features

- Add, edit, delete, and complete tasks
- Inline editing (Double-click, Enter/Blur to save, Esc to cancel)
- Task priorities (1–5)
- Filter tasks (All, Active, Completed)
- Sort by Created Time or Priority
- Persistent storage using a generic `useLocalStorage<T>` hook
- Clear Completed tasks
- Live task counts
- Dynamic document title
- Responsive modern UI with gradient styling

# Technologies

- React
- TypeScript
- Vite
- CSS3
