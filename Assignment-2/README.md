# Assignment 2 – Interactive Task Board

# Overview

A Task Board built with React, TypeScript, and Vite that demonstrates state management, controlled components, immutable updates, and component-based architecture.

# Features

- Add tasks
- Reject empty or whitespace-only titles
- Toggle task completion
- Delete tasks
- Filter tasks (All, Active, Completed)
- Live task counts
- Immutable updates using spread, map, and filter
- Stable keys using task.id
- Typed props

# Components

- App
- TaskInput
- TaskList
- TaskItem
- FilterBar
